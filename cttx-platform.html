📦 REPLICATION GUIDE — HOW TO ONBOARD A NEW CLIENT
  • STEP 1Fill in "New Project Setup" above → downloads a project JSON config to config/
  • STEP 2Drop the project JSON in config/ folder alongside oya-project.json
  • STEP 3Select the project from the dropdown (top-right). All tabs load from that config.
  • STEP 4Add nodes to the Fibre Design tab. Run OTDR calculations. Map the ring.
  • STEP 5Share WhatsApp report template with field tech. Parse daily via Reports tab.
  • STEP 6Generate client reports from Reports tab. Export as PDF via Print.
  • RESULTFull engineering lifecycle: Survey → Design → Build → Test → Commission → Report — in one platform, for any client.
